# План покупок 
- **Автор:** Серегин Максим, группа УБ-62
- **Вариант:** 3 — План покупок
- **Назначение:** консольная программа для списка покупок. `amount` — стоимость в целых рублях, `completed` — покупка сделана.
- **Python:** 2025.2.0.1

## Запуск

```
python main.py
```

Тесты:

```
python -m unittest -v
```

`data.json` ищется в папке проекта, поэтому проект можно распаковать в любое место.

## Структура

| Файл | Назначение |
| --- | --- |
| `logic.py` | проверка записей, добавление, поиск, статус, удаление, статистика |
| `storage.py` | чтение и запись JSON (UTF-8), без диалогов |
| `main.py` | меню, ввод, сообщения |
| `test_logic.py`, `test_storage.py` | автоматические тесты (26 проверок) |
| `data.json` | вымышленный набор данных |

## Формат данных

Список записей:

```json
{"id": 1, "title": "Молоко", "category": "продукты", "amount": 90, "completed": true}
```

- `id` — положительное целое, уникальное;
- `title`, `category` — непустые строки (пробелы по краям убираются при добавлении);
- `amount` — целое число ≥ 0 (`bool` не принимается);
- `completed` — строго `bool`.

Новый `id` = максимальный + 1 (для пустого списка — 1); после удаления id не перенумеровываются.
Повреждённый файл не перезаписывается: программа сообщает причину и завершается.

## Результаты сценариев приёмки

| Сценарий | Результат |
| --- | --- |
| Файла нет | пустой список, меню доступно — проверено вручную |
| `[]` | статистика из нулей — `test_empty_statistics`, `test_empty_list` |
| Суммы 4 и 2, одна завершена | всего 2, 1/1, сумма 6 — `test_statistics_two_categories` |
| Название ` Python ` | сохраняется `Python` — `test_add_strips_and_sets_status` |
| Поиск `PY` | найдено — `test_find_case_insensitive` |
| Пустое название, `-1`, `abc` | повторный ввод — вручную и `test_parse_amount` |
| Статус неизвестного ID | сообщение, данные не изменены — вручную, `test_set_completed_unknown_id` |
| Удаление отменено | запись сохранена — вручную |
| Удалён ID 1 из {1, 2} | остаётся ID 2, новая получает 3 — `test_ids_after_delete` |
| Сохранение и перезапуск | `test_roundtrip` |
| Повреждённый JSON / повторный ID | запуск прекращён, файл не изменён — вручную, `test_broken_json_not_modified`, `test_bad_structure_and_duplicate_id` |
| Ошибка сохранения | сообщение об ошибке, меню остаётся — `test_save_error` |
