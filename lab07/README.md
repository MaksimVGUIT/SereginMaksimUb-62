## Вопросы для защиты
- **Возврат и вывод.** `return` передаёт значение вызывающему коду и завершает функцию; его можно сохранить, передать дальше, проверить в `assert`. `print()` только показывает текст человеку, значение не возвращает (функция вернёт `None`).
- **Локальная переменная и параметр.** Параметр — имя в определении функции, получает значение (аргумент) при вызове. Локальная переменная создаётся внутри функции и существует только во время вызова. Результат наружу передаётся через `return`, `global` не нужен.
