# Таблица для цикла суммирования чисел 1–4

Пусть программа имеет вид:

```python
total = 0

for i in range(1, 5):
    total += i
```

| Итерация | `i` | `total` до | `total` после |
|---:|---:|---:|---:|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |

После завершения цикла: `total = 10`.

# Дополнительное задание: проверка простоты

Файл `prime.py` проверяет, является ли целое `n >= 2` простым.

Делители перебираются начиная с `2`, пока выполняется:

```python
divisor * divisor <= n
```

Если найден делитель без остатка, число составное.

Если ни одного такого делителя нет, число простое.

 Проверки

`2` → `YES`

`9` → `NO`

`17` → `YES`

`49` → `NO`

Проверяется только до `sqrt(n)`, потому что если у числа есть делитель больше квадратного корня, парный делитель обязательно будет меньше квадратного корня.

Рекурсия сама по себе не делает алгоритм логарифмическим. В этой программе используется обычный цикл, поэтому количество проверок растёт примерно как `sqrt(n)`.\

Почему цикл `for i in range(...)` завершится?
Цикл гарантированно завершается, потому что функция `range()` генерирует строго ограниченную, конечную последовательность элементов. На каждом шаге итератор выдает следующее значение. Когда элементы в последовательности заканчиваются, цикл автоматически прекращает свою работу. Внутренняя логика программы не изменяет счетчик вручную, что исключает риск бесконечного зацикливания.

Почему `range(a, b)` не всегда соответствует условию Задания №1?
1. Исключение правой границы: Функция `range(a, b)` работает в полуоткрытом диапазоне `[a, b)`. Это означает, что число `b` никогда не включается в перебор, в то время как по заданию вывод должен быть *включительным*. Для движения вверх необходимо использовать `range(a, b + 1)`.
2. Направление движения: Если `a > b` (нужно идти на убывание), стандартный вызов `range(a, b)` вернет пустой диапазон, так как шаг по умолчанию равен `+1`. Чтобы генерировать последовательность по убыванию, требуется явно передать отрицательный шаг и скорректировать границу: `range(a, b - 1, -1)`.
